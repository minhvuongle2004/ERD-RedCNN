# Câu 1: Ảnh CT là gì và tại sao cần nó?

## 🎯 Mục tiêu
Sau khi đọc xong, bạn sẽ hiểu:
- CT scan là gì
- CT dùng để làm gì trong y học

---

## 📖 Trả lời

### CT là gì?

**CT** = **C**omputed **T**omography (Chụp cắt lớp vi tính)

Đơn giản: **Chụp X-quang từ nhiều góc để tạo ảnh 3D bên trong cơ thể**

### So sánh với X-quang thường

```
X-quang thường:                    CT scan:
┌──────────────┐                  ┌──────────────┐
│   📷         │                  │   📷        │
│    ↓         │                  │  ↙ ↓ ↘     │ (quay 360°)
│  ┌─────┐    │                  │  ┌─────┐    │
│  │ 🫁  │    │ → 1 ảnh phẳng   │  │ 🫁  │    │ → Nhiều ảnh
│  └─────┘    │                  │  └─────┘    │ → Ghép thành 3D
│    ↓         │                  │  ↗ ↓ ↘     │
│   📄         │                  │   🖥️        │
└──────────────┘                  └──────────────┘
```

### Tại sao cần CT?

**1. Nhìn rõ bên trong cơ thể**
- Não
- Phổi
- Gan, thận
- Xương, khớp

**2. Phát hiện bệnh**
- Khối u, ung thư
- Chảy máu nội
- Gãy xương phức tạp
- Viêm nhiễm

**3. Lên kế hoạch điều trị**
- Xác định vị trí chính xác
- Đo kích thước khối u
- Theo dõi sau điều trị

### Ví dụ thực tế

```
Bệnh nhân bị đau đầu dữ dội:

Bước 1: Chụp CT não
        ↓
Bước 2: Phát hiện chảy máu não
        ↓
Bước 3: Bác sĩ biết chính xác vị trí
        ↓
Bước 4: Phẫu thuật cấp cứu ngay
        ↓
        ✅ Cứu sống bệnh nhân
```

## 🖼️ Ví dụ ảnh CT

### Ảnh CT phổi:
```
┌─────────────────────┐
│   Phổi trái  Phổi phải  │
│      🫁        🫁       │
│                        │
│   Tim ❤️               │
│                        │
│   Cột sống 🦴          │
└─────────────────────┘
```

Nhìn ảnh này, bác sĩ có thể thấy:
- Phổi có khối u không?
- Tim to bất thường không?
- Xương có gãy không?
